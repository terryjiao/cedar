# Cedar 开发进度

更新日期：2026-10-23。当前发布版本：[v0.1.0 预览版](https://github.com/terryjiao/cedar/releases/tag/v0.1.0)，MIT 许可证。

## 已完成

- 版本固定的 GitHub Skill 入口与预构建工具包，用户无需手动克隆或构建 Cedar。
- 有范围限制的只读资料采集，保存来源、原文、哈希和遗漏。
- 宿主 coding agent 根据 Skill 生成任务覆盖图，区分明确需求、推断、已有检查和建议检查。
- JSON 结构、来源、原文引用和状态一致性校验。
- HTML / Markdown 报告和 DSH 静态接入检查。

Cedar CLI 不提供模型推理。语义分析由用户现有 coding agent 完成；静态 DSH 检查标记为 `not-executed`。

## 已有验证

v0.1.0 发布时，22 项自动化测试和 TypeScript 检查通过。实际发布包在空目录与全新 npm 缓存中完成合成资料采集、校验和报告流程，目标文件保持不变。

公开 Skill、安装包与校验文件均已验证无需登录即可获取，下载内容一致。通过公开包地址实际执行版本查询、Skill 读取和合成资料采集成功。这些结果证明工具与分发流程可用，不证明任务覆盖完整或模型分析优于通用 coding agent。

## 如何继续开发

先阅读 [下一里程碑](next-milestone.md)，再结合 [架构](architecture.md) 核查运行时事实并制定实现计划。不要把路线图中的目标写成已实现能力，也不要把静态检查当作执行验证。

每个里程碑完成后同步更新本文件的状态与验证依据；范围或优先级改变时，更新 [路线图](roadmap.md) 和下一里程碑。公开发布过的版本链接与资产保持固定。
